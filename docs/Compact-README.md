# ScreenLossless v1.0.0 精简版

本版保留与便携版相同的录制功能，通过使用电脑已安装的运行环境减小体积。

**需要 Windows 10/11 x64 和 .NET 8 Desktop Runtime x64。** 普通 .NET Runtime、ASP.NET Runtime 或仅安装 .NET 9/10 都不能替代所需的 .NET 8 桌面运行环境。可安装 .NET 8 SDK x64，它包含所需运行环境。

官方安装页面：https://dotnet.microsoft.com/download/dotnet/8.0 ，选择 **.NET Desktop Runtime → Windows → x64**。

安装运行环境后，完整解压本软件 ZIP，再双击 ScreenLossless.exe。没有运行环境时会显示 .NET 的安装提示；希望解压即用，请选择 Portable 便携版。

使用说明见 [使用说明](UserGuide.md)。ffmpeg.exe、ffprobe.exe 与两类许可证目录均为有效运行/分发内容，请保留。

**FFmpeg 对应源码独立提供：ScreenLossless_FFmpeg_9.0.2_Source.zip，与本软件在同一个 Release / 下载页获取。** 发布者必须在运行包链接旁提供源码链接；离线再次分发时一并交付源码 ZIP。详见 [FFmpeg-SOURCE.md](FFmpeg-SOURCE.md)。

界面右上角可选择跟随系统、中文或 English。中文 Windows 显示语言默认中文，其他语言默认英文；手动选择会被记住，空闲时立即生效。

The UI defaults to Chinese on Chinese Windows systems and English otherwise. Change **System default / 中文 / English** beside the window buttons. Your choice is remembered and applies immediately while idle.
