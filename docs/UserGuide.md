# ScreenLossless v1.0.0 使用说明

Windows 10/11 x64 屏幕录制工具，支持全屏、区域、窗口录制，以及系统声音和麦克风采集。

## 启动与录制

双击项目根目录 Start-ScreenLossless.bat，或运行 releases/v1.0.0/Portable/ScreenLossless.exe。Portable 便携版解压即用；Compact 精简版需要 .NET 8 Desktop Runtime x64。Portable / Compact 的 FFmpeg 和 ffprobe 应保留在程序旁。也可直接打开 Standalone 单 EXE 版，内置运行环境与录制组件，首次运行自动准备用户缓存，无需在程序旁放其他文件。详见[单 EXE 版说明](Standalone-README.md)。

1. 选择全屏、区域或窗口。首次打开默认全屏；退出时保存设置，再次打开恢复所选模式与有效区域。
2. 在「视频」页选择帧率、编码和录制用途。没有独立显卡也可选择 H.264 CPU 或 MPEG-4 CPU，低配可配合 15/30 FPS 与较低输出尺寸。
3. 在「声音」页启用系统声音、麦克风，选择系统默认或指定设备并调整音量。混音开启时保存一个音轨，关闭后分别保存。
4. 在「输出」页设置尺寸、MKV/MP4、分段规则和输出目录。
5. 点击开始录制。倒计时可取消；录制中使用浮窗暂停、继续或停止。停止后等待合成完成。合成时视频流直接复制，音频单独按时间线补齐或裁切，避免按取整时长裁掉视频尾帧。

## 界面主题

语言选择旁使用一个日夜切换按钮：月亮切换为黑夜，太阳切回白天。首次启动默认白天，退出后记住选择，下次启动恢复。设置页、下拉框、滚动条、弹窗、托盘菜单及录制浮窗同步换色。录制或暂停时切换会保留窗口、选区和录制状态。

## 编码与画质

自动选择置顶，可用编码从轻量压缩到高保真无损排列，不可用编码统一放在底部；重新检测后保留当前选择。

可选 NVIDIA H.264/HEVC、Intel QSV、AMD AMF 以及 CPU 编码，实际可用项由本机试编码结果决定；缺少相应硬件或驱动时显示不可用。

需要逐像素保真可用 x264rgb 或 FFV1；NVENC 4:4:4 无损仍涉及色彩空间转换。H.264 CPU、MPEG-4 和常规硬件压缩编码为有损方案，适合降低占用或文件大小。自动方案在硬件初始化失败时可尝试兼容捕获与 CPU 回退。手动指定的编码器失败时会显示原因。

### HEVC 10-bit 4:4:4 编码无损

在「视频 → 视频编码」选择「HEVC NVIDIA · 10-bit 4:4:4 编码无损」。此选项与普通「HEVC NVIDIA · 压缩 / 有损」独立；压缩画质设置不影响它，建议原始尺寸与 MKV。

需要支持 HEVC 10-bit、4:4:4 和无损模式的 NVIDIA 显卡及驱动；是否可用由真实试编码、ffprobe 格式检查以及编码前后 YUV 帧哈希比较共同决定。ffprobe.exe 必须与 ffmpeg.exe 位于同一目录。缺少支持时标为不可用；手动选择不会偷偷改为有损编码。

输出为 HEVC Rext、10-bit YUV 4:4:4、BT.709 全范围。GDI、DXGI 和现代窗口捕获共用同一转换流程；DXGI 会下载画面进行 CPU 色彩转换，再交给 NVENC 编码，因此不承诺全 GPU 流程或更低 CPU 占用。支持暂停、继续、连续分段和视频流复制合并；MP4 也可保留视频编码，但部分播放器不支持此格式。

这里的无损指转换后的 10-bit YUV 数据：解码与编码前一致。FFmpeg RGB 转换测试中观察到最多 1 级色值差异，不承诺 RGB 逐像素可逆；严格 RGB 保真仍选 x264rgb / FFV1 和原始尺寸。当前捕获源为 8-bit SDR，10-bit 编码不代表支持 HDR 或原生 10-bit 桌面采集；缩放仍会改变原始像素。

## 区域边框与浮窗

选区显示深色描边＋浅色细芯的置顶虚线，适应浅色、深色及与主题色相近的背景；边角和编辑手柄保留主题色。边框略带透明度，全部位于裁切区域外。未录制时从外侧边线移动，从边角拉伸；区域内部允许鼠标穿透。重新选择时隐藏旧框，取消后恢复。退出再打开时恢复仍位于有效桌面范围内的区域与虚线。

未开始录制时不显示控制浮窗。开始后显示倒计时、启动状态、实际开始时间和有效录制时长；暂停不累计时长。浮窗可拖动，提供暂停/继续、停止、返回主界面；保存结束后关闭。辅助页或托盘菜单可找回浮窗。

区域录制尽量把浮窗放在选区外；全屏录制可能录入浮窗。「防止浮窗被录入」采用 Windows 录屏排除机制，部分远程桌面或截图环境可能看不到浮窗。找回浮窗会关闭防录入并重新定位。

边框与浮窗在普通桌面保持置顶。Windows 安全桌面和独占全屏不保证覆盖。录制时边框鼠标穿透，暂停时边角标识变为琥珀色，深浅对比轮廓保持清晰。

## 状态、预览与设备

「刷新预览」取得单帧画面，不持续抓屏。录制状态显示时间、帧数与当前操作提示，不累积历史日志，不导出或自动生成日志文件。自动停止保存后保留本次停止原因。

点击设备诊断可查看编码试运行结果、音频端点与显示器 DPI。没有 AMD 或 Intel 编码硬件时，相应试编码失败不影响其他可用编码器。

声卡断开时视频继续，缺口补静音；约每两秒重试。默认设备模式跟随系统端点，指定设备模式等待原设备恢复。暂停、停止或离开声音页会释放相应预览设备。

## 保存与恢复

「打开最近」打开本次运行中最近保存的文件；「打开文件夹」在系统资源管理器中查看录像和截图。软件不维护历史记录列表。

异常退出、取消保存或合成失败后，原始素材保留在输出目录的 .screenlossless-work 中。使用「恢复录制」选择素材并重新合成；恢复窗口只显示当前操作提示。已恢复素材可确认后清理，完成的录像保留。不要直接删除未恢复素材。

磁盘不足、显示器实际布局变化、目标窗口关闭/最小化/改变尺寸时，会尝试停止并保存已有内容。真实显示布局变化不支持录制中无缝切换。

## 窗口与快捷键

右上角提供日夜切换、最小化、最大化/还原和关闭按钮；拖动顶部空白移动窗口，双击切换最大化，边缘调整尺寸。录制中关闭会提示停止并保存。

默认 Ctrl+Alt+F9 开始/停止、Ctrl+Alt+F10 暂停/继续、Ctrl+Alt+F8 截图，可在辅助页修改。快捷键冲突会显示提示。下拉框支持方向键、Home/End、前缀定位、Enter 确认和 Esc 取消。

## 功能边界

自动降帧通过重启编码器完成，可能有间隔；不自动降低分辨率。分段大小是分组目标，不保证每个文件严格小于指定值。数小时真实音画同步、各种显卡与实体设备热插拔仍需按实际硬件验证，方法见 HARDWARE-VALIDATION.md。
